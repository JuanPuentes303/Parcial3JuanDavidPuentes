# Monitor de tickets de soporte

Proyecto Ionic + Angular adaptado para cumplir con los primeros 3 puntos del enunciado:

1. **Dashboard e interfaz responsive** con `ion-header`, `ion-toolbar`, `ion-card` e `ion-grid`, incluyendo una métrica dinámica.
2. **Servicio HTTP** inyectable con `HttpClient` para consumir APIs de JSONPlaceholder.
3. **Filtro interactivo** usando `ion-searchbar`, `ion-input` e `ion-select`, actualizando el listado en tiempo real.

## APIs usadas

- `https://jsonplaceholder.typicode.com/posts`
- `https://jsonplaceholder.typicode.com/users`

Los datos del API se transforman localmente en tickets de soporte.

## Ejecutar el proyecto

```bash
npm install
npm start
```

Luego abrir `http://localhost:4200`.
